POST /api/v1/user/bookings
  │
  ├── [TRANSACTION] ──────────────────────────────────────────────┐
  │   1. Verify user                                              │
  │   2. Check serviceability                                     │
  │   3. Check active booking limit                               │
  │   4. Validate scheduled time                                  │
  │   5. Find nearest store ($geoNear)                           │
  │   6. Assign store (atomic $inc with capacity check)          │
  │   7. Create booking → status: STORE_ASSIGNED                 │
  ├── [COMMIT] ───────────────────────────────────────────────────┘
  │
  │   Response: 201 { bookingId, status: "STORE_ASSIGNED", store: {...} }
  │
  └── [BACKGROUND JOBS] ─────────────────────────────────────────┐
      │                                                           │
      ▼                                                           │
   ┌─────────────────────────────────────────────────────────┐   │
   │              DRIVER SEARCH FLOW                          │   │
   │                                                          │   │
   │  Round 1 (5km radius)                                   │   │
   │    ├── isBookingAwaitingDriver? ─── No ──→ STOP         │   │
   │    ├── Update status → DRIVER_SEARCH                    │   │
   │    ├── findAvailableDrivers() ── $geoNear + $lookup     │   │
   │    │                                                     │   │
   │    ├── Drivers found?                                    │   │
   │    │   ├── YES → notifyDrivers() → Push notifications   │   │
   │    │   │         scheduleAcceptanceTimeout(60s)          │   │
   │    │   │                                                 │   │
   │    │   │   ┌── Timeout fires (60s later) ──────────┐    │   │
   │    │   │   │   isBookingAwaitingDriver?             │    │   │
   │    │   │   │   ├── No (driver accepted) → STOP ✅   │    │   │
   │    │   │   │   ├── Yes + more rounds → Next round   │    │   │
   │    │   │   │   └── Yes + last round → AUTO CANCEL ❌│    │   │
   │    │   │   └───────────────────────────────────────┘    │   │
   │    │   │                                                 │   │
   │    │   └── Driver accepts (anytime during search):      │   │
   │    │       handleDriverAccept()                          │   │
   │    │       ├── Atomic findOneAndUpdate                   │   │
   │    │       │   (status=DRIVER_SEARCH + no driverId)     │   │
   │    │       ├── status → DRIVER_ASSIGNED ✅              │   │
   │    │       └── All timeout/search jobs become no-ops    │   │
   │    │                                                     │   │
   │    └── NO drivers found                                 │   │
   │        ├── More rounds? → scheduleNextRound(10s delay)  │   │
   │        └── Last round? → AUTO CANCEL ❌                 │   │
   │                                                          │   │
   │  Round 2 (7.5km) → Same flow                           │   │
   │  Round 3 (10km)  → Same flow (final)                   │   │
   │                                                          │   │
   └─────────────────────────────────────────────────────────┘   │
                                                                  │
   ┌─────────────────────────────────────────────────────────┐   │
   │              AUTO CANCEL FLOW                            │   │
   │                                                          │   │
   │  autoCancelBooking()                                    │   │
   │    ├── [TRANSACTION]                                    │   │
   │    │   ├── Booking.status → CANCELLED                   │   │
   │    │   ├── cancelledBy → "SYSTEM"                       │   │
   │    │   ├── isActive → false                             │   │
   │    │   ├── Timeline entry added                         │   │
   │    │   └── Store.current_booking_count -= 1            │   │
   │    ├── [COMMIT]                                         │   │
   │    │                                                     │   │
   │    ├── Queue: User notification                         │   │
   │    │   "Sorry, no driver available. Booking cancelled." │   │
   │    │                                                     │   │
   │    └── Queue: Refund (if payment was PAID)              │   │
   │        "Refund ₹420 to user"                            │   │
   │                                                          │   │
   └─────────────────────────────────────────────────────────┘   │
                                                                  │
   ┌─────────────────────────────────────────────────────────┐   │
   │              USER CANCEL FLOW                            │   │
   │                                                          │   │
   │  PUT /bookings/:id/cancel                               │   │
   │    ├── [TRANSACTION]                                    │   │
   │    │   ├── Booking.status → CANCELLED                   │   │
   │    │   ├── cancelledBy → "USER"                         │   │
   │    │   └── Store.current_booking_count -= 1            │   │
   │    ├── [COMMIT]                                         │   │
   │    │                                                     │   │
   │    └── Driver search jobs become no-ops                 │   │
   │        (isBookingAwaitingDriver returns false)           │   │
   │                                                          │   │
   └─────────────────────────────────────────────────────────┘   │
      └──────────────────────────────────────────────────────────┘
